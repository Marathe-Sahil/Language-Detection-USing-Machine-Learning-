# Language-Detection-USing-Machine-Learning-

Language Detection using Machine Learning
This project is aimed at building a Language Detection model that can classify the language of a given text. It uses machine learning techniques, and a trained model to distinguish between different languages, such as English, Japanese, Chinese, Marathi, and more.

Project Overview
The model uses the langdetect library for language identification. It can classify input text into several languages by training with diverse data sources. This tool is useful for text processing applications that require language-specific handling.

Features:
Detects multiple languages (e.g., English, Japanese, Chinese, Marathi).

Simple to integrate into larger projects.

Provides accurate predictions for short and long sentences.
